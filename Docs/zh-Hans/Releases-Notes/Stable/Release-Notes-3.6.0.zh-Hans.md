# RunProcess 3.6.0

> [English](../../../en/Releases-Notes/Stable/Release-Notes-3.6.0.md) · 简体中文 · [繁體中文](../../../zh-Hant/Releases-Notes/Stable/Release-Notes-3.6.0.zh-Hant.md)

## 新增

- **远程执行** - 配对另一台 Mac，在同一个窗口里把命令发过去执行，支持工作流和 sudo。此前仅预览版提供，现并入正式版。
- **工作流** - 存放在 `workflows.yml` 里的多行脚本，用短名称触发。补全时排在别名之前，执行前先展开。
- **远程访问策略** - 由被控端按能力逐项决定远程客户端能做什么：执行命令、运行工作流、以 root 执行、修改别名、读取或清除历史、访问文件。命令中出现违禁词会被拒绝。
- **配对通知** - 6 位配对码通过系统通知送达；通知不可用时回退为应用内弹窗。
- **远程快捷指令** - 快捷指令和 Siri 可以使用「运行远程命令」和「搜索远程历史」。
- **远程执行帮助** - 新增帮助主题，覆盖被控端设置、配对、切换主机、权限与重连。

## 改进

- **远程权限默认全部拒绝** - 打开远程控制不再默认放行任何能力。需要在「设置 → 远程 → 远程权限」里逐项开启，在此之前所有远程请求都会被拒绝。
- **通知权限时机** - 不再在首次启动时索取通知权限，改为在你开启远程控制时请求 —— 这是唯一用到通知的功能。
- **启用后需要重连** - 打开远程控制后，对端需要重新连接：在它的窗口中重新执行一次，或打开一个新窗口。切换主机则是另一个方向：菜单栏的选择会作用于所有已打开的窗口，而新开的窗口默认在本机执行。
- **两端需同版本** - 远程通信协议在不同版本之间并不稳定，请把两台 Mac 一起升级。
- **滚动条** - 设置和帮助改用叠加式滚动条，静止时淡出；滚动视图不再在毛玻璃背景上露出一块白色轨道。

## 修复

- **并发执行** - 两个窗口同时跑 sudo，或快捷指令与窗口并发时，不再互相取消。取消范围仅限发起方自己那一次执行。
- **补全面板** - 改为每个窗口一份，不再是全局单例，不会再跟着最后请求的窗口跑。
- **窗口阴影** - 透明窗口在改变尺寸后阴影会停在旧位置，现在每次尺寸变化都会重新计算。
- **日志隐私** - 调试输出不再包含你执行的命令和客户端 token 哈希。
- **本地化** - 工作流补全的副标题和握手失败提示原本是硬编码中文，现已本地化。
- **CI 构建 Release** - CI 现在会真正构建 Release 配置；此前的流程构建的是 Debug，即使 Release 构建失败也可能显示通过。

## 迁移

从 3.5.0 升级：无需迁移。现有的 `aliases.yml`、`history.yml`、`paths.yml` 继续有效；`workflows.yml`、`remote_hosts.yml`、`paired_clients.yml`、`remote_access.yml` 会在首次使用时创建。

从预览版切换：两版使用独立的数据目录（`RunProcess` 与 `RunProcess-Beta`），别名、历史、工作流和已配对主机不会迁移。切换后请重新配对远程主机。

远程控制默认关闭。如需开启，请显式授予相应的能力。

## 说明

应用未公证。首次打开时右键点击应用，选择打开，然后确认。

更新包使用 EdDSA 签名，安装前会验证。密码和签名密钥不存储、不传输。

需要 macOS 13.0 或更高版本。
