# RunProcess 3.6.0

> [English](../../../en/Releases-Notes/Stable/Release-Notes-3.6.0.md) · [简体中文](../../../zh-Hans/Releases-Notes/Stable/Release-Notes-3.6.0.zh-Hans.md) · 繁體中文

## 新增

- **遠端執行** - 配對另一台 Mac，在同一個視窗裡把指令傳過去執行，支援工作流和 sudo。先前僅預覽版提供，現併入正式版。
- **工作流** - 存放在 `workflows.yml` 裡的多行腳本，用短名稱觸發。補全時排在別名之前，執行前先展開。
- **遠端存取原則** - 由被控端依能力逐項決定遠端用戶端能做什麼：執行指令、執行工作流、以 root 執行、修改別名、讀取或清除歷史、存取檔案。指令中出現禁用詞會被拒絕。
- **配對通知** - 6 位配對碼透過系統通知送達；通知不可用時退回為應用程式內彈窗。
- **遠端捷徑** - 捷徑和 Siri 可以使用「執行遠端指令」和「搜尋遠端記錄」。
- **遠端執行輔助說明** - 新增輔助說明主題，涵蓋被控端設定、配對、切換主機、權限與重新連線。

## 改進

- **遠端權限預設全部拒絕** - 開啟遠端控制不再預設放行任何能力。需要在「設定 → 遠端 → 遠端權限」裡逐項開啟，在此之前所有遠端請求都會被拒絕。
- **通知權限時機** - 不再在首次啟動時索取通知權限，改為在你開啟遠端控制時要求 —— 這是唯一用到通知的功能。
- **啟用後需要重新連線** - 開啟遠端控制後，對端需要重新連線：在它的視窗中重新執行一次，或開啟一個新視窗。切換主機則是另一個方向：選單列的選擇會作用於所有已開啟的視窗，而新開啟的視窗預設在本機執行。
- **兩端需同版本** - 遠端通訊協定在不同版本之間並不穩定，請把兩台 Mac 一起升級。
- **捲軸** - 設定和輔助說明改用疊加式捲軸，靜止時淡出；捲動視圖不再在毛玻璃背景上露出一塊白色軌道。

## 修正

- **並行執行** - 兩個視窗同時跑 sudo，或捷徑與視窗並行時，不再互相取消。取消範圍僅限發起方自己那一次執行。
- **補全面板** - 改為每個視窗一份，不再是全域單例，不會再跟著最後請求的視窗跑。
- **視窗陰影** - 透明視窗在改變尺寸後陰影會停在舊位置，現在每次尺寸變化都會重新計算。
- **日誌隱私** - 除錯輸出不再包含你執行的指令和用戶端 token 雜湊。
- **在地化** - 工作流補全的副標題和握手失敗提示原本是硬編碼中文，現已在地化。
- **CI 建置 Release** - CI 現在會真正建置 Release 配置；先前的流程建置的是 Debug，即使 Release 建置失敗也可能顯示通過。

## 移轉

從 3.5.0 升級：無需移轉。現有的 `aliases.yml`、`history.yml`、`paths.yml` 繼續有效；`workflows.yml`、`remote_hosts.yml`、`paired_clients.yml`、`remote_access.yml` 會在首次使用時建立。

從預覽版切換：兩版使用獨立的資料目錄（`RunProcess` 與 `RunProcess-Beta`），別名、歷史、工作流和已配對主機不會移轉。切換後請重新配對遠端主機。

遠端控制預設關閉。如需開啟，請明確授予相應的能力。

## 說明

應用程式未公證。首次開啟時右鍵點擊應用程式，選擇打開，然後確認。

更新套件使用 EdDSA 簽名，安裝前會驗證。密碼和簽名金鑰不儲存、不傳輸。

需要 macOS 13.0 或更新版本。
